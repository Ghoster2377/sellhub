# SellHub — панель на вашем компьютере (постоянная версия)

Эта папка — полноценная панель продавца FunPay + Playerok, которая работает
**на вашем компьютере и не зависит от чата с агентом и от интернета-сервисов**.
Ключи от площадок уже лежат внутри (`data\credentials.json`) — площадки
подключатся сами при первом же запуске.

## Установка (один раз)

1. **Python.** Если на компьютере ещё нет Python:
   - откройте https://www.python.org/downloads/
   - нажмите жёлтую кнопку **Download Python 3…**
   - запустите установщик, **поставьте галочку «Add python.exe to PATH»**
     (внизу первого окна установщика) и нажмите **Install Now**.
2. Распакуйте архив в удобную папку, например `C:\SellHub`
   (правой кнопкой по архиву → «Извлечь всё…»).
3. Дважды кликните по файлу **`start.bat`**.
   Он сам установит компоненты (нужен интернет, 1–2 минуты), запустит сервер
   и откроет панель в браузере.

Готово. Адрес панели на этом компьютере — всегда **http://localhost:8000**
(можно добавить в закладки).

## Ежедневное использование

- **Включить панель:** дважды кликнуть `start.bat`.
- **Выключить панель:** закрыть свёрнутое окно «SellHub-сервер»
   или дважды кликнуть `stop.bat`.
- Автозапуск вместе с Windows (по желанию): нажмите `Win+R`, введите
  `shell:startup`, Enter; скопируйте в открывшуюся папку ярлык файла `start.bat`.

## Если ключ перестал работать (площадка показывает «ключ отклонён»)

Ключи живут в браузере, где вы залогинены на площадке:

- **FunPay:** сайт funpay.com → F12 → вкладка **Application** → слева
  **Cookies → https://funpay.com** → строка **golden_key** (копия значения).
  Туда же нужен User-Agent: откройте https://whatmyuseragent.com и скопируйте строку.
  Вставьте оба значения в панели на вкладке «Настройки» → блок FunPay → «Подключить».
- **Playerok:** сайт playerok.com → F12 → **Application → Cookies →
  https://playerok.com** → строка **token** (копия значения) → вставьте
  в настройках панели в блок Playerok.

Панель сохраняет ключи у себя в папке (`data\credentials.json`) и дальше
подключается сама.

## Безопасность

- В папке панели лежат ключи от ваших аккаунтов — **не отправляйте папку
  и архив никому** и не выкладывайте в интернет.
- Панель работает в режиме чтения плюс действия, которые вы сами нажимаете
  (ответить в чат, завершить сделку). Ночью сама ничего не делает:
  автовыдача отключена по вашему желанию.

## Обновления панели

Новые версии агент собирает в такой же архив. При обновлении распакуйте
новый архив **поверх старой папки**, но сохраните папку `data`
(в ней ключи) — просто не заменяйте её при копировании.

## Доступ с телефона (из домашней сети, по желанию)

В файле `start.bat` замените `127.0.0.1` на `0.0.0.0`, перезапустите панель,
и на телефоне в той же Wi-Fi-сети откройте `http://<IP-компьютера>:8000`
(IP виден в панели Windows: `win+R` → `cmd` → `ipconfig`, строка IPv4,
например `192.168.1.35`).
